# dthqsz-cpu.github.io

个人 GitHub Pages 的**用户站点**根目录。发布来源是 `main` 分支的根路径，
所以放在这里的文件会直接出现在 <https://dthqsz-cpu.github.io/> 下面
（项目站点则各自带着自己的目录名，比如 <https://dthqsz-cpu.github.io/tg-checkin-dashboard/>）。

## 这里有什么

| 文件 | 用途 |
| --- | --- |
| `3586a40de05cc6dfc352fa07b031a3ac.txt` | 第三方站点验证文件，内容是一串令牌 |
| `index.html` | 根路径的极简页面，只给一个入口 |

没有隐私信息，也没有可执行的东西。改动直接提交到 `main` 即可发布。
